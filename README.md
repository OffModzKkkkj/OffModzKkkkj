## 🔬 Research Projects

### 1. **FocusGuard** - Cognitive Load Detection via Computer Vision
A machine learning system that detects cognitive distraction and mental workload in real-time using facial expressions, gaze direction, and head posture. Employs Random Forest classification with applications in productivity optimization and human factors research.

**Key Contributions**: Feature engineering from visual data, real-time classification, privacy-preserving analysis.

**Technologies**: Python, OpenCV, scikit-learn, Pandas

**Paper**: [FocusGuard: Real-time Cognitive Distraction Detection System](/FocusGuard/research/focusguard_paper.tex)

---

### 2. **MoodSync** - Emotional State Detection via Typing Dynamics
An investigation into biocomportamental dynamics through typing rhythm analysis. MoodSync predicts emotional states (happy, sad, neutral, stressed) using Support Vector Machines trained on keystroke dynamics.

**Key Contributions**: Biometric feature extraction, multi-class emotional classification, passive emotion detection.

**Technologies**: Python, scikit-learn, SVM, Data Simulation

**Paper**: [MoodSync: Biocomportamental Analysis via Typing Dynamics](/MoodSync/research/moodsync_paper.tex)

---

### 3. **CrowdSense** - Urban Space Optimization via Open Data Analysis
A predictive system for crowd density forecasting in public spaces using open data integration. Combines public transport schedules, event calendars, weather data, and temporal features to predict overcrowding levels.

**Key Contributions**: Multi-source data integration, urban analytics, Random Forest ensemble methods.

**Technologies**: Python, scikit-learn, Data Simulation, Urban Computing

**Paper**: [CrowdSense: Crowd Prediction via Open Data](/CrowdSense/research/crowdsense_paper.tex)

---

### 4. **DebugMind** - LLM Fine-tuning for Software Engineering Education
An AI system exploring Large Language Model fine-tuning for transforming cryptic programming error messages into clear, pedagogically effective explanations. Focuses on improving the learning experience for novice programmers.

**Key Contributions**: LLM fine-tuning strategies, educational AI, semantic understanding of programming errors.

**Technologies**: Python, Transformers, NLP, T5/Llama Fine-tuning

**Paper**: [DebugMind: LLM Fine-tuning for Error Explanation](/DebugMind/research/debugmind_paper.tex)
